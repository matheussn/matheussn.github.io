Por que criei meu hub digital (portfólio + blog + produtos) e como hospedei no GitHub Pages

Construir um hub digital próprio me dá independência, velocidade e foco. Eu queria um fluxo enxuto para publicar artigos, listar projetos e divulgar produtos digitais — sem depender de plataformas pesadas.

Com Next.js exportado de forma estática, consigo performance, simplicidade e custos quase nulos. O GitHub Pages cuida do deploy enquanto eu me concentro no conteúdo e na evolução dos produtos.

Decisões de arquitetura

  • Site 100% estático via next export.
  • Blog em MDX para flexibilidade de componentes.
  • Ads e analytics só em produção, com consentimento.

Publicação

O workflow do GitHub Actions empacota e publica a pasta out/. Para domínio próprio, basta configurar o CNAME.
